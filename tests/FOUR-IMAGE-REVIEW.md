# 四張來源截圖的 JSON／SVG／KaTeX 驗證

日期：2026/11/03

## 測試範圍

使用對話中的 GPT 辨識使用者提供的四張截圖，人工建立固定 JSON；沒有使用 OpenAI／DeepSeek API。來源輪廓座標只用於重建外觀，數學條件依據題文及明確標示，未以像素推算未知數，也未把答案填入學生題目。

## 修正

- 獨立模組支援題文中的行內 LaTeX。
- 模組先完整建構所有區塊，再替換預覽，避免後段公式錯誤時留下半份題目。
- 限制模組 SVG 預覽高度並保留長寬比。
- v4 SVG 清理允許 font-style，保留頂點字母的斜體。

## 限制

未設定 API Key，因此未驗證「按 AI 轉換按鈕 → 外部模型辨識圖片」的流程。正式練習單每格可用高度取決於頁數、列數與字體設定，仍需依題目長度調整。重建圖形為忠實示意圖，不是量測圖。
