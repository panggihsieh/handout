# Latex數學-圖文練習簿

版本：草稿 `Math's Scrapbook v.1.0`

## 專案簡介

這是一個 A4 直式數學講義排版工具，適合整理國小數學、幾何題與文字應用題。

目前支援：

- 幾何題逐格插入截圖
- 文字題逐格貼上文字
- LaTeX / Markdown 題目渲染
- 每格獨立調整題目字體大小
- 右側計算程序區顯示對應題號
- 直接列印或另存 PDF

## 操作流程

### 1. 基本設定

上方可設定：

- 標題
- 姓名
- 日期
- 起始編號
- 頁數
- 列數
- 每格輔助線
- 家長簽名顯示 / 隱藏

### 2. 輸入題目

每一格可獨立輸入題目內容。

#### 幾何題

1. 點選該格的 `插入截圖`
2. 貼上剪貼簿中的圖片，或使用瀏覽器允許的圖片剪貼簿內容
3. 題圖會顯示在左側題目區

#### 文字題

1. 點選該格的 `貼上文字`
2. 貼上原始題目文字
3. 可包含：
   - 一般文字
   - Markdown
   - LaTeX 公式

### 3. 調整每格文字大小

每個題目框內都有自己的字體控制：

- `-`：縮小該格文字
- `+`：放大該格文字

這個調整只影響當前那一格，不會影響其他題目。

### 4. 清除單格內容

若要刪除某一格內容，按該格的 `清除` 即可。

### 5. 列印 / 匯出

1. 點選右上角 `列印 / 另存 PDF`
2. 進入列印預覽
3. 可直接列印，或選擇匯出成 PDF
