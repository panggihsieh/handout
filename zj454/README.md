# 數學題目 JSON 自動轉換與渲染模組

這是獨立原型，尚未整合到原本的 `v4/index.html`。AI 產生之題目必須人工核對。需要 Node.js 20+ 和網路連線（瀏覽器會載入 KaTeX、DOMPurify 的 CDN 資源）。

## Windows 11 解壓縮

1. 下載 `zj454.zip` 到「下載」資料夾。
2. 在檔案總管對 ZIP 按右鍵 → **全部解壓縮**。
3. 先選擇暫存目的地，例如 `K:\CODEX\handout`，並留意是否出現雙層 `zj454\zj454`。
4. 正確放置後應有 `K:\CODEX\handout\zj454\package.json`、`server.mjs` 與 `public\index.html`。
5. 解壓縮路徑只是示例；若實際 Codex 專案在別處，請換成實際資料夾。

## 執行

1. 開啟 PowerShell，輸入 `cd K:\CODEX\handout\zj454`（需自行替換路徑）。
2. 執行 `npm install`。
3. 複製 `.env.example` 成 `.env`，填寫有效的 `OPENAI_API_KEY`。
4. 執行 `npm run dev`。
5. 在瀏覽器開啟 `http://127.0.0.1:5185`。

未設定 API Key 時，「AI 轉換」不能使用，但直接貼入 JSON 再按「渲染 JSON」仍可測試（需網路載入前端套件）。API 呼叫另計費。

「AI 轉換 JSON」旁提供圓形百分比與預估倒數，預設估計 60 秒。此數字是等待時間推估，不是供應商回報的實際進度；等待中最多顯示 95%，超過預估後顯示已等待秒數。轉換及渲染成功才顯示 100%；失敗或來源變更導致結果未套用時會停止計時，並顯示該次狀態與耗時。

## 產生類似題

② JSON 中有完整有效的題目後，可按「類似題（AI）」。程式依目前②的 JSON 產生一題合理換數字、自然調整敘述的類題，保留數學關係、所求、單位與限制。含圖題保留 SVG 輪廓與座標，只更新必要的文字標示，不依圖形像素比例計算。

每次成功流程會使用兩次 API 請求：產生新題與獨立 AI 檢核。程式另檢查數字確實改變、文字不僅換數字、SVG 結構未改變。檢核未通過時不顯示新題；AI 檢核不等於形式化數學證明，仍須人工核對。無可調整數字、條件不足或無法保持原圖時，可拒絕產生。

成功後彈出「類似題 JSON 與預覽」，可按「複製新 JSON」，原①②③保持原狀。產生期間若原題變更，不開啟過期結果；新題不包含解答。失敗不自動重試，以免增加費用。線上版沿用瀏覽器直連供應商，本機版使用 `/api/variant`；均使用目前已解鎖的設定。

## 安全注意

- `.env` 已列入 `.gitignore`，絕不要提交私密 API Key。
- 此範例只監聽本機 127.0.0.1；部署到公開網站時，需要額外做認證、速率限制和安全驗證。
- JSON 合法不代表數學內容一定正確。請教師人工檢查題文與圖形。
- 本示範為完整原型，但不保證已與既有練習簿程式相容；整合任務請見 `CODEX-INTEGRATION.md`。

## 本專案新增功能

- 在頁面按 Ctrl+V 可貼上 PNG、JPEG 或 WebP 截圖（上限 7 MB）。
- 「載入測試題」可在未設定 API Key 時驗證文字、LaTeX、SVG 渲染。
- 「彈跳預覽」開啟題目對話框，可用關閉按鈕或 Esc 返回。
- 這是獨立模組，執行目錄為 `K:\CODEX\handout\zj454`，不修改 v4 練習簿。
- 不會自動讀取其他專案的 API Key；請自行設定此目錄內的 `.env`。

## API 設定（新增）

可直接在模組或 v4 彈窗內選擇 OpenAI、Gemini、DeepSeek、Qwen，貼上金鑰與解鎖密碼，測試成功後才加密儲存；儲存後不再顯示或提供複製金鑰，解鎖僅供程式使用，更換需重新貼上並測試。不必修改 `.env`；前端 AI 轉換需要先啟用或解鎖設定。原有 `.env` 僅保留給自行從本機 API 呼叫的相容用途。

詳細供應商確認、使用方式、限制與驗證記錄見 [API-SETTINGS.md](API-SETTINGS.md)。MiniMax 尚未接入。連線測試與轉換可能由供應商計費；正式連線仍需有效金鑰。

## 三欄動態連動

- ①修改文字或更換截圖時，②③會標示待重新轉換，預覽保留並淡化；不自動呼叫付費 API。
- ②編輯後停頓 350 ms 自動驗證並更新③；JSON／公式錯誤會顯示原因、保留上次有效預覽並停用複製／彈跳預覽。
- 手動修改②會更新③，但若①已變更，仍保留「尚未核對①」提示。
- AI 轉換成功後②③同步更新；轉換期間若①或②變更，舊回覆不套用。
- 載入四圖案例或一般測試題會同步①②③，並清除不相符的舊截圖。
- 驗證：`node tests/three-panel-sync.test.mjs`，另已以瀏覽器確認來源變更提醒、JSON 錯誤提示及有效分數自動渲染；沒有發出付費 API 請求。
