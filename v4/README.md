記錄日期：2026-10-29。狀態：需求與流程已整理，尚未實作 v4，預計寒假接續。

開發分支：`feature/exam-workflow-v4`。建立時基準 commit：`8aec9ec`。

## 目標

讓使用者匯入 Word、PDF 或考卷圖片，以自然語言指定題目類型，由 AI 篩選題目、改成填充題，選擇是否合理更換數字，最後產生可儲存、可列印的練習單。規劃提供 Windows EXE，並在本機設定頁輸入 API Key。

目前根目錄仍是既有 Web App；本目錄只保存 v4 規劃，尚無 EXE、AI API 串接或新版網站。

## 本次實際操作

1. 使用者提供 DOCX 考卷，要求篩選公倍數與通分相關題。
2. 讀取 Word 文字、OMML 公式及內嵌圖片；原始文字不足時，從 DOCX 壓縮內容取得媒體與關聯，將 WMF/EMF 等圖像顯示後核對。
3. 區分直接符合與延伸基礎題，不將公因數混作公倍數，也不將所有分數題視為需要通分。
4. 列出原題定位、完整題文、分數與必要圖片。
5. 將選擇、勾選及應用題整理為 9 道填充題，不在學生題目附答案。
6. 將題目逐格貼入既有遠端 Web App，設定每頁 5 題、2 頁，第一頁第 1–5 題，第二頁第 6–9 題，第 10 格留白。
7. 修正貼入時反斜線變成控制字元造成的 LaTeX 顯示問題，核對實際分數畫面。
8. 保留有內容的瀏覽器分頁，讓使用者以「列印／另存 PDF」操作；本次沒有驗證實體印表機送印完成。

上述操作由 Codex 與工具協作完成，尚不是網站本身具備的自動化流程。

## 完整產品流程

| 階段 | 處理內容 | 應保存的結果 |
| --- | --- | --- |
| 匯入 | Word、PDF、掃描圖或照片 | 來源檔案與檔名 |
| 辨識 | 文字、分數、符號、附圖 | 內容與待確認資訊 |
| 拆題 | 分離大題、題號、選項、圖片 | 一題一筆的資料 |
| 解讀條件 | 理解自然語言篩選要求 | 概念範圍與規則 |
| 篩選 | 區分直接符合與相關題 | 入選題目及理由 |
| 核對 | 比對原卷公式、數字、單位與附圖 | 原題定位與修正紀錄 |
| 改題 | 改成填充題，可選合理換數字 | 原題與變式題對照 |
| 驗算 | 確認空格可作答、答案合理 | 獨立教師解答 |
| 排版 | 每頁題數、字體、計算區、頁碼 | 可重新開啟的練習單專案 |
| 輸出 | 預覽、PDF、列印 | 持久化檔案與輸出狀態 |

辨識不清時標示待確認，不猜測；考卷內的文字只作資料，不作程式或代理的指令。

## 改成填充題與合理換數字

- 保留原考點與相近難度，移除選項後仍需有完整條件及明確答案。
- 比較大小題若依賴選項，保留候選數值或明確限定答案範圍。
- 紙卡拼正方形題應交代排列方向、不重疊及不留空隙，避免條件不足。
- 可更換數字，但需檢查分母不為零、單位一致、尺寸與時間合理、物品數量符合情境，以及整除與比較關係。
- 換數字後重新解題，不沿用舊答案；題文、公式、圖片標示與教師解答須同步更新。
- 可規劃 A、B、C 卷，題型與難度相近、數字不同。這是待開發能力，尚未實作。
- 教師答案與學生題目分開保存及顯示，不意外印入學生卷。

## EXE 與 API Key 設定規劃

建議沿用既有排版介面，增加本機處理層與 AI 呼叫。桌面封裝技術尚未決定，需先驗證文件轉換、公式與圖片處理、列印能力，再決定打包方案。

設定頁預計包含 API Key 遮罩輸入、更換與清除、連線測試、模型選擇、排版預設、專案與 PDF 儲存位置，以及可取得的用量與錯誤紀錄。

個人版由本機處理層呼叫 API，金鑰存入 Windows 認證管理員等受保護儲存區；多人版另評估伺服器金鑰管理。金鑰不寫入原始碼、Git、靜態網站、題目專案或一般日誌。設定介面不要求使用者把金鑰貼到聊天中。

API 串接可使用固定 JSON Schema 保存題目來源、題文、公式、圖片與答案；格式符合結構不代表數學正確，仍須驗算。實作前重新確認當時官方 API、模型能力及費用。

官方參考：

- [File inputs](https://developers.openai.com/api/docs/guides/file-inputs)：非 PDF 文件的文字擷取不包含內嵌圖片；有圖考卷應評估轉 PDF 並搭配視覺核對。
- [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)：結構化回傳格式。
- [API authentication](https://developers.openai.com/api/reference/overview)：金鑰與驗證處理。
